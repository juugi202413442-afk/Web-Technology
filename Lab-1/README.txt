# BookNest — Lab Experiment 1

## Aim
Design a website for book information where:
1. The home page contains a list of books.
2. Clicking a particular book opens the book information on the next page.

## Files
- `index.html` — Home page with the book list.
- `book.html` — Book details page. The selected book is displayed using JavaScript.
- `style.css` — Complete responsive styling.

## How to run
Open `index.html` in a browser. Click any book card to open its details page.

## Key features
- Clean, original-looking editorial design
- Six book entries
- Separate details page
- Responsive layout for desktop and mobile
- JavaScript-based book data
- Hover interactions and polished typography
